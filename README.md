# Personal website

A static personal portfolio for GitHub Pages, using iA Writer Duo and the approved Sections layout.

- `index.html` contains the biography and three category links.
- `interactions/index.html`, `making-art/index.html`, and `comparative-psychology/index.html` list the work in each category.
- Individual project pages live beside their category index. Each links back to its category.
- `styles.css` provides the shared typography, purple palette, and responsive layout.
- `assets/` contains images and local font files.

All pages work without JavaScript or a build step. Update category entries and detail pages together when changing project information. Keep image proportions intact.

GitHub Pages serves the root homepage after changes are pushed to the configured branch.
