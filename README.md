# Personal website

A static, text-led personal website for GitHub Pages, using the approved Notes design.

- `index.html` contains the biography and grouped project links.
- `styles.css` provides the shared iA Writer Duo typography, purple palette, and responsive layout.
- `interactions/` contains three full project pages.
- `making-art/uneven-geography.html` contains the drawing and its artist statement.
- `making-art/on-remembering.html` contains the aluminum-sheet artwork and its artist statement.
- `making-art/printmaking.html` contains the printmaking photographs.
- `comparative-psychology/learn-how-pigeons-learn.html` contains the lab description and pigeon photograph.
- `assets/` contains images and font files.

All pages contain static HTML and work without JavaScript or a build step. Keep relative links aligned with page locations. Update both homepage summaries and detail pages when changing project facts.

GitHub Pages serves the root homepage after changes are pushed to the configured branch.
