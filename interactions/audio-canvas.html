Audio Canvas (Spring 26)

Audio Canvas is an exploratory concept for translating drawings into sound. Recent text-to-sound models can generate audio for virtually any text input. The system cannot refuse or say there is no corresponding sound. This opens up the possibility of translating things that have no obvious sonic identity into sound.

What makes something "sonically friendly" or "sonically elusive?" "Rain" carries a relatively identifiable sonic signature. "Flowers?" probably less so. My interest is to treat this distinction as a starting point, using generative sound to probe (1) which things translate easily and which resist it, (2) how Generative AI systems, as cultural technologies, reveal our own sonic associations.

The process sends a drawing through two generative stages. A vision-language model interprets the image of a drawing and writes text prompts. A text-to-sound model then converts those prompts into audio. Varying the prompt instructions changes what the first model describes, which steers what the second model generates.

Across experiments, the system gravitated toward sonically obvious elements and overlooked the rest. Cropping smaller regions showed that the same pixels produce different sonic descriptions depending on surrounding context. Sonically elusive elements produced sounds that were often harder to describe and impossible to evaluate whether they are "accurate" or not.
